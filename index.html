Auto-accept without losing the thread

AI edits arrive fast — sometimes too fast to follow. Voight captures the stream in real-time, organizing scattered changes into coherent, reviewable segments. You don't have to slow down to stay informed. When the code matters, you'll know what changed.

"

When you're deep in a system — optimizing performance, refactoring architecture, shipping something that matters — you need to know what AI actually did. Not because you don't trust it, but because the code is yours to maintain. Voight keeps you engaged without slowing you down.

01

Timeline View

See the full sequence of AI edits across your project.

When AI edits span many files, reviewing file-by-file loses the architectural thread. The timeline shows navigation markers like — preserving the order so you can reconstruct how a complex feature was built.
02

Segments

Review AI changes at your own pace.

AI-generated code is parsed into reviewable chunks. Each click advances to the next segment and jumps your cursor to the relevant lines. From the timeline, drill down into any segment.
03

BYOK Explanations

Ask a second opinion on what the code actually does.

Send any segment to an AI for an isolated explanation of what the code actually does—independent of what you asked for. Bring your own API key.
04

Context Markers

Leave breadcrumbs for your future self.

Mark what matters. Flag complex logic, leave notes for yourself. When you return to this code — next week or next year — your annotations will be waiting.
05

Complexity Indicators

Know where the risk lives before you commit.

A lightweight cyclomatic complexity score flags functions with denser logic. Visible throughout your review, highlighting where to pay closer attention. Currently supports Go, TypeScript/JavaScript, and Python.
