Understanding at the speed of shipping.

A VS Code extension that surfaces AI-generated code in reviewable segments. Stay familiar with your codebase without slowing down.

Install for VS Code View on GitHub →

AI writes code fast. You accept, commit, move on. Over time, the codebase becomes unfamiliar—yours in name, but not in understanding. When something breaks, you're debugging a stranger's code. Voight isn't about checking AI's work. It's about staying engaged with your own system.

Segments

AI-generated code is parsed into reviewable chunks. Step through them one at a time—each click advances to the next segment and jumps your cursor to the relevant lines.

BYOK Explanations

Send any segment to an AI for an isolated explanation of what the code actually does—independent of what you asked for. Bring your own API key.

Context Markers

Leave notes on segments for yourself. Mark complex logic. Leave breadcrumbs for when you return to this code later.

Complexity Indicators

A lightweight cyclomatic complexity score flags functions with denser logic. Know where the risk lives before you commit.

How It Works

Voight detects AI by its velocity signature—bursts of code faster than human typing. It uses diff algorithms to capture these injections, parses them against function boundaries into discrete segments, and evaluates control flow to flag complexity. Entirely read-only: no modification, no commit blocking. Just organized visibility.
